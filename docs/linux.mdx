## Linux support

Both the Dart package (`thermion_dart`) and the Flutter package (`thermion_flutter`) now work on Linux.

`thermion_flutter` provides an EGL/GTK-based platform texture, so you can embed a Filament rendering surface inside a Flutter app on Linux. It links against GTK 3 (`pkg-config gtk+-3.0`), which must be available on your system.

Filament has been built for Ubuntu 22.04; other distributions may work, but YMMV.

Contributions are welcome. Join the Discord if you want to help out.
