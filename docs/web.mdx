## Web

Web support is still experimental and currently requires you to manually compile Thermion to WASM first.

To run from Flutter:

```
flutter run -d chrome --web-header=Cross-Origin-Opener-Policy=same-origin --web-header=Cross-Origin-Embedder-Policy=require-corp
```

The `Cross-Origin-Opener-Policy` and `Cross-Origin-Embedder-Policy` headers are required because the WASM build uses shared memory across threads; the page will not load without them.

Requirements:

1) GNU Make
2) CMake
3) Emscripten

From the project root directory:

```
make wasm
```

This downloads the prebuilt Filament WebGL2/WASM binaries (cached after first download) and compiles Thermion to WASM under `thermion_dart/native/web`.

### Flutter

Copy `thermion_dart.js` and `thermion_dart.wasm` to the `/web` folder for your target app.


```
flutter run -d chrome --web-header Cross-Origin-Embedder-Policy=require-corp --web-header Cross-Origin-Opener-Policy=same-origin
```
