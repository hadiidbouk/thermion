## Animations

Thermion supports three kinds of animation, all driven through the `ThermionAsset` returned by `viewer.loadGltf(...)`:

1. **glTF animations** — skeletal/morph animations baked into the glTF file.
2. **Morph targets** — manually driving individual morph target weights.
3. **Bone animation** — manually constructing per-bone animation frame data.

## glTF animations

A glTF asset can embed one or more named animations. List them, then play by index or name:

```dart
final asset = await viewer.loadGltf("assets/character.glb");

final names = await asset.getGltfAnimationNames();
// e.g. ["Walk", "Run", "Idle"]

final duration = await asset.getGltfAnimationDuration(0); // seconds

await asset.playGltfAnimation(0,
  crossfade: 0.2,      // seconds to blend in
  replaceActive: true, // stop other animations
  loop: true,
);

// later
await asset.stopGltfAnimation(0);
// or by name:
await asset.stopGltfAnimationByName("Walk");
```

You can also scrub to a specific time with `setGltfAnimationTime(index, seconds)`.

## Morph targets

Morph targets let you blend between vertex states (e.g. facial expressions). First discover the targets on a renderable entity, then set all weights at once:

```dart
final asset = await viewer.loadGltf("assets/cube_with_morph_targets.glb");

// Names for the asset's root entity:
final targetNames = await asset.getMorphTargetNames();
// e.g. ["Open", "Close"]

// setMorphTargetWeights takes weights for ALL morph targets on the entity.
// To activate only one, set the rest to 0.
await asset.setMorphTargetWeights(entity, [1.0, 0.0]);
```

> **Important:** `setMorphTargetWeights` accepts the *child mesh entity* that owns the morph targets, not the asset root. Use `getChildEntity` / `getChildEntityNames` to find the right entity. `getMorphTargetNames`, by contrast, takes the parent entity and a mesh name.

For keyframed morph animation, build a `MorphAnimationData` and pass it to `setMorphAnimationData`. Clear it later with `clearMorphAnimationData(entity)`.

## Bones / skeletal animation

You can inspect and directly animate a skeleton:

```dart
final bones = await asset.getBones();          // List<ThermionEntity>
final boneNames = await asset.getBoneNames();  // List<String>
final count = await asset.getBoneCount();
```

To play a custom bone animation, **reset bones to their rest pose first**, then enqueue the animation:

```dart
await asset.resetBones();
await asset.addBoneAnimation(animation);  // BoneAnimationData
```

By default, bone animation frame data is interpreted in *parent bone space* — a 45° rotation around Y rotates the bone 45° around its parent's current Y axis, not the rest pose. `Space.ParentBone` and `Space.Model` are supported.

You can also set a bone's transform directly with `setBoneTransform(boneEntity, Matrix4 transform)`.

## Notes

- Call `asset.addAnimationComponent()` to attach an animation component if one isn't present, and `removeAnimationComponent()` to detach it.
- Don't call animation methods while the app is backgrounded — see the [Animations when backgrounded](./filament#animations-when-backgrounded) footgun.
- A runnable example mixing glTF animations and morph targets is in `examples/flutter/animations`.
